# Machtverflechtungen

**Wer wusste was? Wer finanzierte wen? Wer konnte eingreifen? Welche Institutionen profitierten? Welche Aussage ist tatsächlich belegt?**

Dieses Projekt dokumentiert weltweit Fälle und Strukturen an den Schnittstellen von Staat, Nachrichtendiensten, politischer Gewalt, organisierter Kriminalität, Überwachung, Wirtschaft, Lobbyismus und informellen Elitennetzwerken.

## Was das Projekt anders macht

Es gibt keine gemeinsame Schublade „Verschwörung“. Stattdessen werden konkrete Beziehungen einzeln geprüft:

- Person → Organisation
- Behörde → Quelle
- Organisation → Finanzierung
- Dienst → Operation
- Ereignis → Gesetzesänderung
- Netzwerk → nachweisbarer Einfluss

Jede belastende Relation benötigt eine Quelle.

## Zwei Ebenen

### Dokumentation

Was ist durch Primärquellen, Urteile, Untersuchungsausschüsse oder Forschung nachweisbar?

### Hypothesenprüfung

Welche weitergehende Erklärung könnte die Befunde verbinden? Welche Beweise fehlen? Welche Alternativerklärung konkurriert damit?

Dadurch dürfen Hypothesen riskant sein, ohne als Tatsachen ausgegeben zu werden.
